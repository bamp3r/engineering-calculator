# Engineering Calculator

## Как открыть
Скопируйте `index.html` на ваш компьютер и дважды кликните по файлу. Откроется в браузере – никаких установок не требуется.

## Функции
- Арифметические операции: `+  -  *  /  ^  %` (деление на 100)
- Скобки `(`, `)`
- Факториал `!` (постфиксный)
- Функции: `sqrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `ln`, `log` (log10), `log2`, `abs`, `exp`
- Константы `pi`, `e`
- Тригонометрия в градусах (`DEG`) и радианах (`RAD`). Переключается кнопкой `DEG`.
- Клавиатура: цифры, операторы, `Enter`/`=` для вычисления, `Backspace` – удалить последний символ, `Escape` – очистить.
- Память: `MC` (очистить), `MR` (вставить), `M+` (добавить результат), `M-` (вычесть результат). При ненулевой памяти рядом с кнопкой `MR` появляется `#mem`.
- История: кнопка `H` открывает список последних 10 вычислений. Клик по элементу вставляет его в поле выражения.

## Горячие клавиши
- `0–9`, `.` – ввод числа
- `+  -  *  /  ^  %  (  )` – операции
- `Enter` / `=` – выполнить
- `Backspace` – удалить последний символ
- `Escape` – очистить
- `Alt+H` – показать/скрыть историю
- `Alt+M` – показать/скрыть память (не реализовано в UI, но кнопки доступны)

## Тесты
Запустите `node tests/run.js` – в консоли должна появиться строка `ALL PASSED`.
