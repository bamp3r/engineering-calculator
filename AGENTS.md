# Правила

- Работай только в этой папке.
- Весь код калькулятора в одном файле index.html (HTML, CSS, JS в одном файле).
- Запрещено: eval(), new Function(), внешние библиотеки.
- Логика вычислений: чистые функции в блоке <script>. Код, который работает с DOM,
  выполняй только внутри проверки: if (typeof document !== 'undefined') { ... }
- В конце скрипта обязательно: if (typeof module !== 'undefined') { module.exports = { evaluate }; }
- Сигнатура: evaluate(expression, mode) где mode равен 'DEG' или 'RAD'.
  Возвращает число или бросает Error. Синтаксис выражений: + - * / ^ ( ) , функции
  sqrt( sin( cos( tan( asin( acos( atan( ln( log( (log это log10) log2( abs( exp(,
  постфикс ! для факториала, константы pi и e.
- Проверка кода: node tests/run.js. Задача не закончена, пока она не печатает ALL PASSED.
- Не делай git push и не создавай репозитории, пока я явно не попрошу.
- Комментарии в коде на русском.
